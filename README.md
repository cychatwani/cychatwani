## 🚀 What I'm building

### 🌬️ BreezeBuild

An experiment that started with a simple question:

> **What if AI could build Spring Boot applications without producing absolute chaos?**

BreezeBuild is my attempt at an opinionated, AI-guided platform for building production-ready backend applications.

Think:

- 🤖 AI-assisted development
- ☕ Java 21 + Spring Boot
- 🧠 Agentic workflows
- 🏗️ Architecture-aware generation
- 🔐 Secure secret handling
- 📦 Small, reviewable code changes
- 🔭 Proper observability
- 🚀 Eventually... deployment too

Still early. Still evolving. Still breaking things.

That's the fun part.
